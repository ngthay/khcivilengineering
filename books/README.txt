KCE LIBRARY - BOOK FILES
========================

Put your book files (PDF recommended) in the matching subfolder:

  books/fundamentals/   Dynamics, mechanics, strength of materials, analysis
  books/structural/     Design, concrete, steel
  books/geotechnical/   Soil mechanics, foundations
  books/computing/      AI, Python, programming
  books/softwares/      AutoCAD, ETABS, SAP2000 manuals
  books/standards/      Design codes and standards (ACI, Eurocode, ...)

Then list each file in js/books.js so it shows up on library.html.
The website cannot see a file until it is listed there.

Tip: avoid spaces in file names. Use dashes instead, e.g.
  Reinforced-Concrete-Design.pdf
